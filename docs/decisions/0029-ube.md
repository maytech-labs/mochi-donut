# 0029. ube: checks by package from what the repo declares, results by tree, line-based mutations

- **Status:** Accepted; the base, Rust lints, and `--rerun-failed` changed in [0031](0031-ube-fixes.md)
- **Date:** 2026-10-13

## Context

[ADR 0028](0028-propose-ube-and-taro.md) proposed ube, and [docs/ube/design.md](../ube/design.md) described it, with open questions: whether to have a `.ube.toml`, how to pick tests, which mutation tool to use, and whether the Stop hook helps.

## Decision

- **Checks come only from what the repo declares:** Cargo packages and their `path` dependencies, `package.json` scripts (`test`, `lint`, `typecheck`, `check`), Go modules, pytest projects, matcha drift for docs, and, for the full suite, CI's test, lint, and check commands (`run:` and `script:` lines), else `make check` or `make test`. **No `.ube.toml`.** New files count before they're committed, so a new package is planned on its own.
- **Selection is by package.** A changed file selects its package's checks, and every Cargo package that depends on it, transitively. A workspace-wide change (`Cargo.lock`, the workspace `Cargo.toml`) selects `cargo test --workspace` once. A file nothing covers makes the plan the full suite, and the plan says which file did. What's left out is always listed. Choosing individual test files from history isn't built: package scope is precise enough on the repos tried, and wrong selection is the risk the design worries about most.
- **Results are keyed by tree.** The tree id comes from `git add -A` into a temporary index, then `git write-tree`, so it covers untracked files and leaves the real index alone. `done` passes the checks only for the exact tree they ran on. A green run is recorded in matcha's ledger when matcha is installed.
- **Failure parsers** for cargo test, build, and clippy; pytest; go test; vitest; jest; tsc; and eslint, each giving file, line, test, message, and a rerun command, with a generic `path:line: error` fallback and the output's last lines when nothing parses.
- **`done`'s items:** checks (fail), tests (a warning: a refactor can be right without a test change), and, through matcha, companions, docs, and claims. Without matcha these say unknown, never pass. A test change counts in a test file or inside a Rust file's `#[cfg(test)]` module.
- **`mutate` uses its own line-based operators** (comparisons, `&&`/`||`, `+`/`-`, `true`/`false`) on added non-test lines, outside strings and comments, spread over the change, in a temporary copy of the repo with `node_modules` linked and Cargo builds cached in `target/ube-mutate`. It works the same in every language; cargo-mutants and Stryker are better at one language each.
- **The Stop hook** blocks once when the planned checks haven't passed on the current code, and never when the agent is already continuing because of it. It isn't in the hooks plugin until a trial shows it helps.
- **The process runner and `is_test` moved to `mochi-common`**, shared with yuzu and matcha.
- No new dependencies. ube is 1,730 KB.

## Results (2026-10-13)

- On this repo, a one-line yuzu change plans `cargo test -p mochi-yuzu` and lists CI's `cargo xtask check` as left out; a `mochi-common` change plans it and every package that uses it.
- `ube run` on this branch took 21 s, recorded the green run in the ledger, and `done` caught an edit made after it.
- `ube mutate` on its own `plan.rs` found a line no test proved (the `tests` flag on Go checks). A test now pins it, and 3 of 3 mutations are caught.
- 10 integration tests run the binary against real repos with stub `npm` and `matcha`; breaking dependents, tree keying, or the hook's loop guard each fails one.

## Consequences

- The design's bars (20 PRs in three repos, compact reports in three runners, survivors a reviewer agrees with, use in a trial) are still to measure.
- A package-level plan runs more than strictly needed in big packages.
- Repos whose checks live only in scripts ube can't read get the full suite.

## Alternatives considered

- **Test selection from history now:** finer, but a missed test is false confidence; package scope first, measured, then finer.
- **cargo-mutants and friends:** better per language, but one tool per language, and none for most.
- **Run in place for mutate:** faster, but an interrupted run would leave a mutated file in the user's tree.
