# Code of conduct

mochi-donut follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions, and anywhere else you represent the project.

In short: be respectful, assume good faith, give and take criticism about the work and not the person, and don't harass anyone.

## Reporting

Report a problem privately to the maintainer, trammel-may on GitHub. Don't use a public issue. Reports are kept confidential, and the maintainer will reply within a week.

The maintainer decides what happens, from a warning to a ban, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
